# Deep Coding Thinker

This skill enables deep, sharp, Opus 4.8-level thinking about coding problems.

## Usage Guidelines

- Think deeply about code architecture, edge cases, performance implications, and optimal solutions
- Provide comprehensive analysis covering multiple perspectives
- Identify potential issues before they become problems
- Suggest elegant, efficient, and maintainable solutions
- Go beyond surface-level answers to provide profound insights

## When to Use

- User asks for advanced coding help
- User asks for deep analysis of code
- User mentions needing Opus-level thinking
- Complex architectural or algorithmic problems
- Code optimization or refactoring tasks
- Debugging difficult issues

## Analysis Depth

Always consider:

- Architectural implications
- Performance characteristics
- Security considerations
- Maintainability and scalability
- Edge cases and error handling
- Best practices and patterns
